- terrain_mesh_builder.gd prunes unused sparse halos and does not allocate/cache
  nine-Variant payloads for fine points that cannot be shared normal-field nodes.
  Canonical heights and returned mesh bytes are unchanged; no approximation is
  substituted. The bounded cache now retains useful 32m nodes rather than
  churning thousands of fine interior payloads. Reference switches remain for
  the byte-comparison test, not as Inspector controls.
- DesertSettings Mesh Budget > Far Mesh Metres defaults to 512m. Larger parent
  tiles receive extra canonical vertices, bounded at 64x64. 256m offers more
  distant geometry at added CPU cost; 0 restores legacy parent resolutions.
  The controller certifies EVERY biome-interpolation node covering a tile,
  rather than assuming that Desert corners exclude a Grass enclave. Grass,
  mixed tiles and ALL close mesh resolutions are unchanged. Certificates are
  bounded and cleared when settings/seed are configured again.
- desert_material.gdshaderinc only rotates its projection toward a triangle
  when the smooth normal actually under-projects a steep escarpment. Ordinary
  smooth-versus-triangle differences no longer rotate texture coordinates per
  triangle, reducing the faceted-patch appearance on distant ordinary slopes.
- Broad Rock Relief (Materials, default0.65) adds analytic continuous 180/620m
  exposed-rock surface gradients after source normal-map grain mip-fades.
  Footprint filtering removes unresolved contributions. It is normal-only,
  not a material/color noise mask, and never changes Grass or terrain heights.
  Setting it to0 disables this added relief. The final summed normal remains
  bounded by the existing ~48-degree gradient limit.
- review_dune_matrix.gd discovers NATURAL transverse, longitudinal, barchan,
  star and parabolic landmarks in seeds73921,-91827,214748, then renders each
  through the actual main scene/controller at ground, medium and aerial scales.
  The public exact island mask is used for inland clearance: the height-query
  fast path can return a saturated certificate, not a true shore distance.
  No family selector or terrain height is forced to create a showcase scene.
